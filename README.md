
# Projeto de Criptografia com Fernet

Este projeto é uma aplicação simples de criptografia e descriptografia de mensagens utilizando o módulo `cryptography.fernet`.

## 🔐 Funcionalidades

- Geração de chave criptográfica (Fernet)
- Criptografia de mensagens de texto
- Descriptografia de mensagens
- Interface de linha de comando interativa
- Estilização no terminal com `colorama`

## 🛠️ Requisitos

- Python 3.6+
- Bibliotecas:
  - `cryptography`
  - `colorama`

## 📦 Instalação

```bash
pip install -r requirements.txt
```

## ▶️ Uso

```bash
python main.py
```

Siga as instruções do menu para criptografar ou descriptografar mensagens.

## 📁 Arquivos

- `main.py`: Script principal
- `chave.key`: Arquivo gerado com a chave de criptografia
- `requirements.txt`: Dependências do projeto
